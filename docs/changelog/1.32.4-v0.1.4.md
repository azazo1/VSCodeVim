# VSCodeVim v1.32.4-v0.1.4

Date: 2026-09-14

本版本为 Insert 模式带来 Emacs 风格的光标移动, 并改善了 EasyMotion 词跳转的标记分布, 现有配置无需迁移即可使用.

## Highlights

### Insert 模式 Emacs 光标移动

- 新增 `vim.insertModeEmacsBindings`, 打开后 `<C-b>`/`<C-f>` 按字符左右移动, `<C-p>`/`<C-n>` 按行上下移动, `<C-a>`/`<C-e>` 跳到行首/行尾, `<C-d>` 删除光标右侧的字符.
- 补全列表弹出时 `<C-p>`/`<C-n>` 仍然用于选择补全项, 不会与 Emacs 键位冲突.
- 这套键位会覆盖 Vim 在 Insert 模式下的同名绑定, 默认关闭, 未开启时行为与旧版本一致.

### EasyMotion 词跳转标记间隔

- 新增 `vim.easymotionWordMoveMinSpacing` (默认 2), 为 `w`/`b` 的相邻跳转标记保留最小列间隔, 密集列不再占满候选码; 设为 1 可恢复每个匹配都显示标记.
- 修复每行搜索前没有重置正则 `lastIndex` 的问题, 跨行匹配时后续行的候选不再间歇性丢失.

## Upgrade Notes

- 两个设置均为新增项, 默认值保持旧行为, 现有 VS Code 设置与 `.vimrc` 都无需改动.
- 若此前用自定义按键绑定模拟过 Insert 模式的 Emacs 移动, 可以直接改用 `vim.insertModeEmacsBindings`.
- 安装后重新加载 VS Code 窗口即可使用新行为.
