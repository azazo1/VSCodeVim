# VSCodeVim v1.32.4-v0.1.3

本版本修复 Visual 模式下 VS Code 原生编辑修改 buffer 后光标跳回旧选区的问题, 让外部粘贴, 剪切, 格式化和 Code Action 与 VSCodeVim 内部状态保持一致.

## Highlights

### Visual 外部编辑协调

- Visual 和 VisualLine 的完整选区删除会将光标定位到删除范围起点.
- 完整选区替换沿用 Vim put 落点规则, 字符选区定位到插入内容对应位置, 行选区定位到首个非空字符.
- VisualBlock, 多段修改和无法映射为 Vim 操作的编辑会采用 VS Code 最终 caret 或 selection.
- 外部编辑后的 selection 事件优先完成状态协调, 不再被内部延迟事件误判并忽略.
- 鼠标输入会取消待协调状态, 未收到 selection 事件时会在下一个按键前同步当前 editor selection.

## Upgrade Notes

- 无新增配置或公共扩展 API, 现有设置无需迁移.
- 安装后重新加载 VS Code 窗口即可使用修复后的 Visual 外部编辑行为.
